## Принцип работы

```
┌─────────────────────────┐        Wi-Fi AP (KombiPlus)        ┌──────────────────────┐
│  КОМНАТНЫЙ БЛОК         │◄─────────────────────────────────────►│  БЛОК РЕЛЕ КОТЛА     │
│  NodeMCU v3             │   TCP 8266: SET heat=0/1 sp=...      │  NodeMCU v3 + реле   │
│  DHT11/22 или DS18B20   │◄──────────────────────────────────────│  опц. DS18B20        │
│  OLED + энкодер + веб   │        STATUS relay=... flow=...     │  COM/NO → котёл      │
└───────────┬─────────────┘                                      └──────────┬───────────┘
            │                                                               │
   Телефон / ПК (http://192.168.4.1)                           Клемма термостата котла
   Домашняя сеть (STA, опция)                                  (сухой контакт, низкое напряжение)
```

- Комнатный блок **всегда** поднимает собственную точку доступа. Подключитесь к ней и
  откройте `192.168.4.1` — приложение, облако и учётная запись не нужны.
- Дополнительно блок может подключиться к домашней сети (STA). Точка доступа не
  отключается, потому что к ней подключён блок реле.
- Каждые 2 секунды блок считает потребность в тепле по температуре, уставке и
  гистерезису и отправляет её блоку реле.
- Блок реле выполняет команду; если команд нет **5 минут**, применяется выбранное
  отказоустойчивое поведение.
- Влагозащищённый DS18B20 (опция) передаёт температуру воды в котле.
- Встроены **ночной режим**, **защита от замерзания**, **boost**, **10 тем OLED**,
  **почасовая история**, **файловый менеджер LittleFS** и **OTA**.

## Возможности

### Комнатный блок (`oda_termostati/`)

- **Выбор датчика:** DHT11, DHT22 или DS18B20 одним `#define`
- **OLED 0.96" SSD1306** (128×64, I²C): температура, уставка, состояние, сеть, информация
- **Энкодер KY‑040:** поворот — уставка, короткое нажатие — страницы, длинное — режим
- **10 тем OLED** — редактируемые файлы `/themes/*.txt` в LittleFS
- **8 языков интерфейса** — английский, турецкий, русский, испанский, португальский,
  японский, корейский, китайский. При первом включении блок спрашивает язык (OLED: поворот —
  выбор, нажатие — подтверждение; веб: полноэкранный выбор) и хранит его в `lang=`. На OLED
  доступны en/tr/es/pt (шрифт только ASCII), остальные языки показываются по-английски.
- **Веб-интерфейс для телефона:** уставка, режим, boost, ночной режим, поведение реле,
  MQTT/Telegram, график истории, гистерезис, калибровка, защита от замерзания,
  **сканер Wi-Fi сетей**, системная информация
- **Ночной режим:** другая уставка в заданном интервале (часы по NTP)
- **MQTT:** retained JSON состояния + команды `ключ=значение`
- **Telegram-бот:** статус и управление только для указанного чата
- **LittleFS:** настройки `/config.txt`, почасовая история `/history.csv`, менеджер `/fs`
- **Гистерезис + минимальное время вкл/выкл** против коротких циклов
- **Boost:** +1.5 °C на 5/15/30 минут
- **Защита от замерзания:** нагрев ниже 5 °C даже в выключенном режиме
- **Отказоустойчивость:** при ошибке датчика или потере связи потребность снимается
- **OTA** (только в STA) и mDNS: `http://termostat.local`

### Блок реле (`kombi_rolesi/`)

- Автоматически подключается к точке доступа комнатного блока
- Управляет **сухим контактом** котла через оптоизолированный модуль реле
- **Активный низкий / высокий уровень** — одна строка
- **Отказоустойчивость:** после 5 минут без команд реле размыкается (по умолчанию) или
  удерживает последнюю потребность
- Настройка приходит от комнатного блока (`fs=0/1`) и хранится в EEPROM
- После включения реле **всегда разомкнуто**
- Опциональный DS18B20 для температуры воды
- Светодиод связи и подробный лог 115200

## Быстрый старт

### 1. Среда Arduino

1. **Arduino IDE 2.x** → *Preferences* → *Additional boards manager URLs*:

   ```
   https://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```

2. *Boards Manager* → установите **esp8266** `3.1.2`.
3. *Library Manager* → установите:

   `Adafruit SSD1306`, `Adafruit GFX Library`, `DHT sensor library`,
   `Adafruit Unified Sensor`, `OneWire`, `DallasTemperature`, `PubSubClient`.

   `LittleFSExplorer` и движок тем уже лежат в `oda_termostati/src/`.

4. Плата: **NodeMCU 1.0 (ESP‑12E Module)**, скорость **115200**, flash 4 МБ.

### 2. Настройка

**Одинаковые данные точки доступа в обоих скетчах:**

```cpp
// oda_termostati.ino
#define AP_SSID  "KombiPlus"
#define AP_PASS  "Kombi.1881"

// kombi_rolesi.ino
#define TERMOSTAT_AP_SSID  "KombiPlus"
#define TERMOSTAT_AP_PASS  "Kombi.1881"
```

Выбор датчика в комнатном блоке:

```cpp
#define SENSOR_TYPE  SENSOR_DHT22   // SENSOR_DHT11 / SENSOR_DHT22 / SENSOR_DS18B20
```

Модуль реле с активным высоким уровнем:

```cpp
#define RELAY_ACTIVE_LOW  0
```

### 3. Прошивка и проверка

1. Сначала прошейте **блок реле** (контакт котла пока не подключайте).
2. Затем **комнатный блок**.
3. Подключитесь к `KombiPlus` (пароль `Kombi.1881`) и откройте `http://192.168.4.1`.
4. В логе реле появится `Oda unitesine baglandi.`, в интерфейсе — **Kombi bağlı**.
5. Только после тестов поручите **квалифицированному специалисту** подключить контакт
   реле к клемме термостата котла.

## Логика управления

```
Эффективная уставка = режим ВКЛ → уставка ночного режима, иначе обычная уставка
                                  (+1.5 °C во время boost)
                      режим ВЫКЛ → защита от замерзания (5 °C)

Нагрев ВКЛ : T ≤ уставка − гистерезис  И  прошло ≥ 180 с с последнего выключения
Нагрев ВЫКЛ: T ≥ уставка + гистерезис  И  прошло ≥ 60 с с последнего включения
```

| Параметр | По умолчанию | Диапазон |
|----------|--------------|----------|
| Уставка | 21.0 °C | 5–30 °C |
| Гистерезис | 0.3 °C | 0.1–3.0 °C |
| Мин. время включения | 60 с | фикс. |
| Мин. время выключения | 180 с | фикс. |
| Защита от замерзания | 5.0 °C | 2–10 °C |
| Boost | +1.5 °C | 5/15/30 мин |
| Ночной режим | выкл | 23:00–07:00, 18.0 °C |
| Отказоустойчивость реле | размыкать | размыкать / удерживать |
| Почасовая история | 720 точек | ~30 дней |

Данные датчика старше 30 секунд снимают потребность в тепле.

## Отказоустойчивое реле

Реле замкнуто только если `heat=1` **и** последняя команда моложе 5 минут.

- `fs=0` **(по умолчанию)** — реле размыкается, котёл останавливается. Безопасный вариант.
- `fs=1` — удерживается последняя потребность. Меньше риск замерзания, но есть риск
  перегрева; используйте только при наличии собственного предохранительного термостата котла.
- После подачи питания реле всегда разомкнуто.

## Протокол

Комнатный блок слушает **TCP 8266**, блок реле — клиент. Построчный ASCII:

| Направление | Строка |
|-------------|--------|
| Комната → Реле | `SET heat=1 sp=21.0 hyst=0.3 mode=1 fs=0\n` |
| Реле → Комната | `STATUS relay=1 flow=42.50 rssi=-58 up=123 fs=0 fw=1.1.0\n` |

Оба направления видны в логах 115200.

## Web API

Встроенный сервер отдаёт JSON на порту 80 — удобно для Home Assistant, скриптов и curl.

| Метод | Путь | Пример |
|-------|------|--------|
| GET | `/api/status` | Полный статус JSON |
| GET | `/api/set?sp=22.0` | Уставка |
| GET | `/api/set?mode=0` | Выключить режим |
| GET | `/api/set?hyst=0.4&cal=-0.2&frost=6` | Настройки |
| GET | `/api/set?boost=15` | Boost 15 мин (`0` — отмена) |
| GET | `/api/set?sleep=1&sleepstart=23:00&sleepend=07:00&sleepsp=18` | Ночной режим |
| GET | `/api/set?failsafe=1` | Реле: удерживать потребность |
| GET | `/api/set?theme=gece` | Выбор темы OLED |
| GET | `/api/theme` | Список тем + активная |
| GET | `/api/theme?set=retro` | Выбрать тему |
| GET | `/api/theme?reload=1` | Перечитать файлы тем |
| POST | `/api/net` | Настройки MQTT / Telegram |
| GET | `/api/history?hours=24` | Точки истории |
| POST | `/api/history/sample` | Сохранить точку |
| POST | `/api/history/clear` | Очистить историю |
| GET | `/api/scan` | Wi-Fi сети вокруг (`nets[]`) |
| POST | `/api/wifi` | Поля `ssid`, `pass` |
| POST | `/api/reboot` | Перезагрузка |
| GET | `/fs` | Файловый менеджер LittleFS |

Поля `/api/status`: `fw, theme, temp, hum, sp, eff, hyst, cal, frost, mode, demand, relay, link,
flow, brssi, boost, boostMin, sensorOk, sleepEn, sleep, sleepStart, sleepEnd, sleepSp, failsafe,
mqtt, mqttCfg, mqttPort, mqttPrefix, tg, tgOk, tgErr, tgChat, timeOk, now, hist, fsUsed,
fsTotal, uptime, ip, apip, ssid, sta, rssi, heap, client`.

## MQTT и Telegram

**MQTT** (веб → *MQTT & Telegram*):

- `kombi/status` — retained JSON (`temp`, `sp`, `eff`, `mode`, `demand`, `relay`, `link`, `sleep`, `failsafe`, `boost`, …)
- `kombi/set` — `sp=22.5`, `mode=1`, `sleepsp=18`, `sleepstart=23:00&sleepend=07:00`, `failsafe=1`
- `kombi/result` — `ok` / ошибка

**Telegram**: `/durum`, `/sicaklik 22.5`, `/mod ac|kapat`, `/boost 30`, `/uyku ac|kapat`,
`/uykusaat 23:00 07:00`, `/uykusicaklik 18`, `/yardim`. Отвечает только настроенному чату.

## Память и темы OLED

- `/config.txt` — все настройки (`ключ=значение`), старый EEPROM переносится автоматически
- `/history.csv` — почасовые записи: `время, комната, влажность, уставка, потребность, ночь`
- `/themes/*.txt` — описания тем (`id, header, tempsize, separator, status, nem, boost, su,
  sayfa, etiket, ters, dim`); создаются при первом запуске
- `/themes/active.txt` — id последней темы
- Веб-интерфейс рисует графики за 24 ч / 7 дн / 30 дн; `/fs` — список, скачивание,
  загрузка, удаление и правка файлов

Встроенные темы: `klasik`, `ince`, `dolu`, `kutu`, `nokta`, `dijital`, `neon`, `panel`,
`minimal`, `retro`.

## Безопасность

- В газовом котле есть **230 В**; вскрывать его и подключать контакт должен только специалист.
- Реле подключается как **сухой контакт** к входу термостата котла.
- Используйте **оптоизолированный** модуль реле, предохранитель и качественный блок питания 5 В.
- Смените пароли AP и OTA в реальной эксплуатации; не оставляйте сеть открытой для гостей.
- Проект любительский, **без гарантии**; ответственность несёт пользователь.
- Штатный предохранительный термостат котла должен оставаться в цепи всегда.
